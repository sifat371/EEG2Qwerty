# EEG2Qwerty public package

This package contains reusable, non-sensitive infrastructure that is intended to become the stable public EEG2Qwerty framework.

Current public components:

- `data.sentence_batching` — whole-sentence batching utilities
- `metrics.cer` — dependency-free character-error-rate utilities

Historical architectures remain under `experiments/historical/` until they are reproduced and refactored under the standardized benchmark.

Unpublished research models are not developed in this public package.
