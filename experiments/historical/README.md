# Historical Experiments

This directory preserves completed public-facing experiments from the development lineage.

The names **M0, M1, M2, M3, M4, G1** are experiment identifiers, not released EEG2Qwerty model sizes.

The purpose of preserving these files is to show what was actually implemented and evaluated. Some historical scripts depend directly on the upstream Brain2Qwerty v1 package and were created before the current standardized EEG2Qwerty evaluation framework.

Unpublished research directions are intentionally not included here.
